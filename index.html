Hi! I'm Owen Yajie Liu, a Master's student at Stanford studying Computer Science with Clinical Informatics Management.

I'm interested in AI agents: how we evaluate them, and the data we train them on. Right now I'm working on whether a fast model can tell which of an agent's decisions will fail without running them, and on how numbers should be encoded when models learn from clinical tables.

Research

Evaluating numerical preprocessing methods for tabular representation learning working paper

Owen Yajie Liu, Kara Liu, Michael S. Bernstein · 2026

A neural network only sees vectors, so a value like heart rate has to be encoded first, and that choice decides which differences look big. We test how different encodings change what a variational autoencoder learns about each ICU patient, and which encoding suits which kind of variable.

Trick or Treat: Can a fast AI tell which agent decisions are tricks? working paper

Owen Yajie Liu · 2026

I take decision points from real SWE-agent runs, label each one by replaying it in its environment, and measure how much of the set fast "System 1" models can label at 95% precision, and how much replay that saves.
