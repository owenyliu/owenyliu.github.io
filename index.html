Research

Trick or Treat: Can a fast AI tell which agent decisions are tricks?
Owen Yajie Liu
Working paper, 2026

Takes decision points from real SWE-agent runs, labels each one by replaying it in its environment, and measures how much of the set fast "System 1" models can label at 95% precision, and how much replay that saves.

Evaluating numerical preprocessing methods for tabular representation learning
Owen Yajie Liu, Kara Liu, Michael S. Bernstein
Working paper, 2026

A neural network only sees vectors, so a value like heart rate has to be encoded first, and that choice decides which differences look big. We test how different encodings change what a variational autoencoder learns about each ICU patient.
