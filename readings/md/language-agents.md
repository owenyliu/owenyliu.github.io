# Language Agents: From Next-Token Prediction to Digital Automation — Reading Notes

*Reading notes, November 15, 2026. Source: Shunyu Yao, Princeton University PhD dissertation (May 2024), advisor Karthik Narasimhan. Original PDF: https://ysymyth.github.io/papers/Dissertation-finalized.pdf*

| 项目 | 内容摘要 |
|---|---|
| 文档 | 《语言智能体：从下一词元预测到数字自动化》（*Language Agents: From Next-Token Prediction to Digital Automation*），作者为姚顺雨（Shunyu Yao），是其于 2024 年 5 月提交的普林斯顿大学博士论文，导师为 Karthik Narasimhan。 |
| 核心观点 | 大语言模型不仅能生成文本，还能驱动智能体进行推理、采取行动、接收反馈，并调整行为以完成任务。论文将现实任务评测、推理与规划方法，以及通用智能体架构联系起来。 |
| 什么是“语言智能体”？ | 关键并非使用文本接收指令或输出命令，而是利用内部的自然语言推理，将观察到的信息转化为行动决策。智能体的外部输入和行动也可以涉及图像或其他交互界面。 |

## 主要贡献

| 研究成果 | 具体作用 | 重要意义 |
|---|---|---|
| WebShop | 通过搜索商品、比较产品、选择规格和作出购买决策等购物任务，评估智能体的能力。 | 测试智能体能否在接近真实的数字环境中完成多步骤操作，而不只是回答单个问题。 |
| InterCode | 在交互式编程环境中，评估智能体执行代码、检查反馈并反复尝试的能力。 | 将编程视为探索、测试和调试的迭代过程，而非一次性生成代码。 |
| **ReAct** | 在持续的反馈循环中，将推理、行动与观察交替结合。 | 推理帮助智能体选择行动；行动获得的观察结果又能为后续推理提供证据并纠正错误。 |
| **Tree of Thoughts**（思维树） | 探索并评估多条中间推理路径，通过搜索或回溯，继续推进更有希望的路径。 | 让智能体能够进行更审慎的规划，而不是始终沿着单一推理链前进。 |
| **CoALA** | 提出一种认知架构，将记忆、推理、检索、学习、外部行动和决策过程组织起来。 | 为比较不同智能体系统、识别其能力缺口提供统一框架。 |

## 更深层的启示

| 主题 | 关键洞见 |
|---|---|
| 理解语言，还是记住模式？ | 在一项早期文字游戏实验中，将有意义的观察和行动替换成哈希字符串，并未降低强化学习智能体的表现。这说明，该智能体可能只是在记忆状态标识符，而非真正利用语言的含义。这也推动了对显式运用语言进行推理的智能体的研究。 |
| 行动与规划相辅相成 | ReAct 强调与外部环境交互；思维树强调探索不同的推理路径。论文将外部反馈与内部思考视为提升问题解决能力的两种互补机制。 |
| 数字自动化是目标 | 网页与编程环境既有实际应用价值，也便于开展规模化评测；同时，它们要求智能体应对开放式选择和较长的决策序列。 |
| 一句话总结 | 实用的自主智能体不仅需要一个语言模型，还需要将推理、记忆、工具、反馈与行动选择连接起来的完整系统。论文反映的是截至 2024 年提交时的研究，而不是对当前智能体能力的最新综述。 |
